## 🧭 Sobre
- **Stack principal:** PHP 8.1+/Laravel 10, Node.js, Next.js (App Router), React 18, Tailwind.
- **Infra/DevOps:** Docker/Compose, Nginx, Redis, PostgreSQL/MySQL, CI/CD.
- **Automação & IA:** n8n, integrações com **Huggy**, **Meta Ads/WhatsApp**, **Telegram**, agentes/assistentes.
- **Boas práticas:** SOLID, testes (PHPUnit/Jest), logs e observabilidade.

## 🚀 Destaques recentes
- **APIs REST** desacopladas com Laravel + autenticação **Sanctum/JWT** / Node com Express.
- **Frontends Next.js** com roteamento por app router, SSR/ISR e otimizações de desempenho.
- **Omnichannel**: fluxos automatizados (Meta, Telegram, WhatsApp), segmentação e métricas.
- **Data**: jobs em lote, filas, paginação robusta e consultas otimizadas em PostgreSQL.

- **Backend:** Laravel (Queues/Jobs/Policies), Eloquent avançado, Guzzle, Middlewares.
- **Frontend:** React 18, Next.js App Router, estados (Jotai/Context), UI com Tailwind.
- **Banco de dados:** PostgreSQL (CTEs, Window Functions), MySQL, migrações, índices.
